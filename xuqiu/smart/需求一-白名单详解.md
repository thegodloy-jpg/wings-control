## 1. 口径（4 条裁定）

| # | 裁定 | 约束 |
| --- | --- | --- |
| 1 | 只开关不强制（无 forced） | 有效 = `开关 on` AND `特性 ∈ 白名单`；只收窄、永不强开 |
| 2 | 不管老模型 | miss → 三特性一律不产 |
| 3 | 严格对齐源、不外推 | 每行须有 0430 / day0 出处（§4） |
| 4 | PD 一票否决 | PD 角色下三特性全关（唯一反向） |

4-tuple：`(engine 精确, name_tokens 小写子串, card_tokens 子串|"*", feats frozenset)`。三维**与**、首命中即返回。

## 5. 匹配 / 卡型 / 收口

**卡型 `resolve_card_token`**（[device_utils.py:286](../../wings_control/utils/device_utils.py#L286)）：`details[0].name` → `WINGS_DEVICE_NAME` → 平台后缀(`a3→910c`/`a2→910b`) → 显存(NV)。🔴 Ascend 解析失败 → 整条 `910b/910c` 白名单 miss。

**收口 `apply_effective_feature_enablement`**（[config_loader.py:1806](../../wings_control/core/config_loader.py#L1806)，单一真相源）：

| 特性 | 有效条件 | 不命中 |
| --- | --- | --- |
| sparse | 开关 on AND `sparse∈feats` | `ENABLE_SPARSE=false` |
| offload | 开关 on AND `offload∈feats` | `LMCACHE_OFFLOAD=false` |
| spec | 开关不收口 | 由产出口 gate；**suffix 地板恒产** |
| PD | `get_pd_role_env()` | 三特性全 false |

> `spec∈白名单` 只控**是否升级到 MTP**；不在白名单仍产 suffix 地板（投机能力保留）。

## 6. 各特性产出变体

**架构 → mtp_method**：DeepseekV3/V32→`mtp` · DeepseekV4 / GlmMoeDsa→`deepseek_mtp` · Glm4Moe→`glm4_moe_mtp`(w8a8→`mtp`) · Qwen3_5/Moe→`qwen3_5_mtp` · Qwen3Next→`qwen3_next_mtp` · 其它/MiniMaxM2→无(suffix)。

| 特性 | 变体 |
| --- | --- |
| spec | `<mtp_method>`（mtp+spec∈表+无 LMCache 降级）/ `suffix`（spec 未授·无 mtp·LMCache×投机降级·Qwen3Next·Ascend）/ `eagle3`·`draft_model`（给 draft path）/ `none`（非 vllm） |
| sparse | `indexcache_topk8`(GLM-5.1·Asc) / `indexcache_use_index_cache_topk4`(V4-Flash·NV) / `indexcache_topk4`(其它 INDEXCACHE_ARCHS·NV) / `fp8`(非 IndexCache·NV) / `noop`(Asc 非 GLM-5.1，含 V4-Flash·Asc—630 前) |
| offload | `lmcache_cpu`/`_disk`/`_cpu_disk` `[+auto|+custom][+qat][+cold_start]` / `native_cpu_connector`(V4·Asc) / `native_kv_offloading_backend`(V4-Flash·NV) / `disabled`(GLM-5.1·NV) |

> LMCache×投机降级豁免：**V4-Flash NV(native)+Ascend(CPUOffload)** 均与 MTP 共存 → 保 `deepseek_mtp`（仅 spec∈表时触达）。

## 8. 不变量与验证

| 不变量 | 后果 |
| --- | --- |
| 顺序=优先级，更具体型号排前 | 否则遮蔽（误命中） |
