```python
def _build_lmcache_yaml_dict(engine: str) -> dict:
    config: dict = {}

    # ── L2 门控 ──
    mem_enabled = os.getenv("ENABLE_KV_MEM_OFFLOAD", "false").strip().lower() == "true"
    disk_enabled = os.getenv("ENABLE_KV_DISK_OFFLOAD", "false").strip().lower() == "true"

    # chunk_size（不受门控）
    chunk_size_str = os.getenv("LMCACHE_CHUNK_SIZE", "256")
    ...

    # local_cpu（仅在 L2 mem=true 时）
    if mem_enabled:
        max_cpu_size = os.getenv("KV_MEM_OFFLOAD_SIZE", "").strip()
        config["local_cpu"] = True
        if max_cpu_size:
            config["max_local_cpu_size"] = float(max_cpu_size)

    # local_disk（仅在 L2 disk=true 时）
    if disk_enabled:
        path = os.getenv("KV_DISK_OFFLOAD_PATH", "").strip()
        size = os.getenv("KV_DISK_OFFLOAD_SIZE", "").strip()
        if path:
            config["local_disk"] = path
        if size:
            config["max_local_disk_size"] = float(size)

    # QAT（仅在 L2 disk=true AND L3 QAT=true 时）
    if disk_enabled and get_qat_env():
        config["qat"] = { ... }  # 内部 ENV 名不变
```

## 九、风险与过渡策略

1. **过渡期双读**（建议）：上线窗口期 Maas 可能同时下发新旧 ENV，代码做双读兜底：
   ```python
   _env_offload = os.getenv('ENABLE_KV_OFFLOAD')
   if _env_offload is None:
       _env_offload = os.getenv('LMCACHE_OFFLOAD', 'false')
   ```
   过渡期结束（Maas 确认只发新名）后删除旧名 fallback。

2. **`KV_MEM_OFFLOAD_SIZE="auto"` 向下兼容**：`resolve_offload_cpu_capacity_gb()` 改为字面值 `== "auto"` 判定后，需确保所有调用方（含 V4-Flash 路径的 `_resolve_v4_flash_offload_gb` 和 `_build_deepseek_v4_cpu_offload_config`）正确处理 `"auto"` 字符串，不能直接 `int()` 或 `float()`。

3. **`ENABLE_KV_DISK_OFFLOAD` 拆分影响**：旧代码 `LMCACHE_LOCAL_DISK` 一个变量兼做开关+路径。拆分后 `ENABLE_KV_DISK_OFFLOAD=true` 只是开关，路径由 `KV_DISK_OFFLOAD_PATH` 独立提供。需确保两变量同时下发。

4. **干跑输出快照**：`dryrun_requirement_coverage_output.txt` 和 `cmp_master_branch_output.txt` 包含大量旧 ENV 名的命令行输出，改名后需重新生成并 diff 验证。

5. **测试全量回归**：改名涉及 14 个测试文件，建议写脚本批量替换 + 全量跑 `pytest` 验证。
