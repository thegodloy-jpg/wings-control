## 5. 分析与结论

### 5.1 资源消耗

- **内存 (RSS)**: 每增加一个 worker 进程，约增加 55~65 MB RSS
- **CPU**: 空闲时几乎不占 CPU；负载时 CPU 使用与并发数和 worker 数正相关
- Worker 数超过 CPU 核数时，CPU 调度开销增加但不会额外消耗更多 CPU

### 5.2 TTFT 影响

- Proxy 对 TTFT 的额外开销主要来自进程间路由和网络转发
- 在低并发下，worker 数量对 TTFT 影响很小
- 在高并发下，worker 不足会导致请求排队，显著增加 TTFT

### 5.3 TPS 影响

- Proxy 对 TPS 的影响主要来自 SSE chunk 转发延迟
- 串行场景下 TPS 影响很小（接近直连基线）
- 高并发下 TPS 是否下降取决于 proxy 的 chunk 转发能力
