## 【wings-infer】wings-infer控制服务层解耦

### 一、测试环境与资源

**测试硬件：** L20、H20、910B（A2, 3,4）、910C（A3）

**模型支持：** [具体待补充]GLM4.7
Qwen3.5-397B-A17B
Qwen3.5-27B
MiniMax-M2.5
DeepSeek-V3.2
DeepSeek-V4

**推理框架：** MindIE、vLLM、SGLang、vLLM-ascend

### 二、部署架构与拓扑验证

**容器化部署验证：** 覆盖 wings-control、wings-engine、wings-accel 三容器在 K8s 环境上的组合部署流程（wings-control+wings-engine，wings-control+wings-engine+wings-accel）。

**多拓扑场景覆盖：** 基于上述容器组合，覆盖单机单卡、单机多卡、多机多卡、PD分离等不同拓扑结构的部署验证。

### 三、多引擎适配与命令校验

**统一命令行验证：** 覆盖统一对外引擎命令的正确性验证及非法参数校验。

**四引擎解耦适配：** 验证解耦后对 MindIE、vLLM、SGLang、vLLM-ascend 四种引擎的支持情况，包括命令生成的准确性、特性拼接的正确性及非法性校验。

### 四、历史特性继承与功能验证

**加速特性支持测试：** 覆盖解耦后对历史加速特性的支持测试。

- **范围说明：** 支持稀疏、卸载、投机推理（范围继承超融合版本）；暂不支持软浮点。
- **验证内容：** 验证特性使能、参数配置及功能正确性。

**统一服务化API验证：** 覆盖继承特性的功能验证，重点测试统一服务化 API 的正确性与兼容性。

### 五、性能测试

**历史特性性能测试：** 挑选重点模型（涵盖大语言模型和多模态理解模型），在开启历史加速特性（稀疏/卸载/投机）的场景下进行性能测试，输出性能数据。

**最新框架性能验证：** 选择重点模型在最新开源推理框架（MindIE/vLLM/SGLang/vLLM-ascend）下进行性能验证，确保性能不降低。

### 六、兼容性测试

**版本兼容性：** 覆盖解耦前版本的兼容性验证，确保平滑升级与数据迁移。解耦后推理框架多版本之间的兼容。

### 七、版本升级场景（升级后是否可以，暂不保证）

覆盖解耦后版本平滑升级，功能不影响，性能不降低；

### 八、稳定性

覆盖7*24小时稳定性测试(观察是否崩溃，内存泄露)

### 三、特性生效性验证

**部署后生效性验证：** 覆盖加速特性部署完成后的功能验证，确保所选特性已正确加载、配置生效且功能正常运行。

### 四、性能测试与评估

**历史特性性能测试：** 覆盖历史加速特性在典型模型及最新推理框架下的性能测试，评估性能表现并输出详细的测试报告。

## 【wings-accel】加速特性支持投机解码

### 一、测试环境与资源

**测试硬件：** L20、H20、910B（A2, 3,4）、910C（A3）

**模型支持：** [具体待补充]Qwen3系列，llama

**推理框架：** vllm、vllm-ascend

### 二、测试点覆盖

1. 覆盖开启投机推理特性的部署验证；
2. 覆盖开启投机推理特性部署参数的合法性校验验证；
3. NV覆盖 draft model、eagle使能，且不开启SVIP自验证长度策略，部署模型推理，验证使能效果和模型推理性能，输出性能测试数据报告；
4. NV覆盖 draft model、eagle使能，且开启SVIP自验证长度策略，部署模型推理，验证使能、长度策略效果和模型推理性能，输出draft model、eagle使能且不开启SVIP自验证长度策略的性能对比报告；
5. NV覆盖 draft model、eagle suffix不使能，部署模型推理，验证模型推理性能，输出性能数据报告；
6. NV覆盖 draft model、eagle suffix使能，部署模型推理，验证使能效果和模型推理性能，输出与draft model、eagle suffix不使能的性能数据报告；
7. ST覆盖 draft model、eagle suffix不使能，部署模型推理，验证模型推理性能，输出性能数据报告；
8. ST覆盖 draft model、eagle suffix使能，部署模型推理，验证使能效果和模型推理性能，输出与draft model、eagle suffix不使能的性能数据报告；
9. 稳定性：覆盖7*24小时稳定性测试(观察是否崩溃，内存泄露)

### 三、范围说明

1. SVIP自验证长度策略：只支持NV，且只支持draft model和eagel使能；
2. NV、ST社区版本支持draft model、eagel、sufix各自单独使能，不支持组合使能；

## 【wings-accel】加速特性支持KV稀疏和KV卸载

### 一、测试环境与基础配置

**测试硬件：** L20、H20、910B（A2 B3,B4）、910C(A3)

**支持模型：** 待定

### 二、KV稀疏加速特性测试

**推理框架：** vLLM

**支持模型：**GLM-4.7

**测试目标：** 验证KV稀疏功能的部署、参数合法性及性能表现，同时验证架构与配置约束。

**功能与部署验证：** 覆盖KV稀疏加速特性的部署流程及参数合法性校验。

**硬件兼容性验证：** 在L20/H20（NV Hopper/L架构）上验证功能可用性；在910B系列（B架构）上验证不支持该特性的预期行为。

**Attention机制支持验证：** 验证对MHA/MQA/GQA的支持情况，输出性能测试报告；验证对MLA、DSA的不支持限制。

**运行约束验证：** 验证在开启CUDA GRAPH或跨机分布式部署场景下的限制（即验证不支持开启CUDA GRAPH、不支持跨机分布式）。

**性能测试：** 在典型模型下，对比未开启与开启KV稀疏的性能，验证投机推理的效果，输出性能测试报告。

### 三、KV卸载加速特性测试

**推理框架：** vLLM、vLLM_ascend

**支持模型：**

GLM4.7
Qwen3.5-397B-A17B
Qwen3.5-27B
MiniMax-M2.5
DeepSeek-V3.2
DeepSeek-V4

**测试目标：** 验证KV卸载功能的部署、参数合法性及性能表现，覆盖不同卸载模式与硬件组合的约束。

**功能与部署验证：** 覆盖KV卸载加速特性的部署流程及参数合法性校验。

**冷加载模式验证：** 在ST（910B系列）和NV（L20/H20）硬件上均验证冷加载功能的支持情况。

**QAT压缩模式验证：** 仅在NV（L20/H20）+ Intel环境下验证QAT压缩功能的支持情况；验证非Intel环境下的限制。

**性能测试：** 在典型模型下，对比未开启与开启KV卸载的性能，验证KV稀疏的效果，输出性能测试报告。

### 四、组合场景与投机推理测试（待确定）

**测试目标：** 验证稀疏、卸载与投机推理共用的综合性能。

**场景覆盖：** 覆盖 KV稀疏 + KV卸载 + 投机推理 共用的复杂场景。

**硬件约束：** 鉴于KV稀疏仅支持NV架构，此组合测试重点覆盖L20/H20环境。

**性能测试：** 执行组合场景下的性能测试，输出性能测试报告。

### 五、稳定性

覆盖7*24小时稳定性测试(观察是否崩溃，内存泄露)
